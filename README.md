# Network-Protocol

Course: CSE 438L (Computer Networks Lab)
Tools Used: Cisco Packet Tracer, IP Subnetting, Routing Protocols

Designed and simulated a medium-scale enterprise network using Cisco Packet Tracer, incorporating 3 routers, 2 switches, 6 PCs, and 1 server to emulate interdepartmental communication.

Implemented static routing and configured DHCP and DNS services, ensuring dynamic IP allocation and domain resolution across subnets.

Enabled HTTP services on the server, allowing client PCs to access a sample website, and tested packet delivery using simulation mode and real-time packet capture.

Demonstrated understanding of OSI model, routing logic, and network troubleshooting by simulating failure scenarios and applying corrective configurations.
